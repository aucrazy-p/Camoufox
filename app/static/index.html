首次使用：需要下载浏览器内核

      
控制程序不含内核，以保持安装包小巧、并支持独立升级。首次启动需要：

      
    
        
  • 下载官方 Windows x64 内核 约 1,259 MB
    • 
        
  • 解压后约 2.5GB，保留完整三系统字库（不裁剪）
    • 
        
  • 另需约 50MB GeoIP 数据库，用于时区/语言跟随出口 IP
    • 
        
  • 安装过程峰值需要约 3.8GB 可用磁盘空间
    • 
      

      
下载只从官方 Releases 拉取，失败不会自动尝试第三方镜像。你可以稍后在「内核管理」里手动开始。

设备指纹

      

        
        
      

      

      
语言决定浏览器界面、navigator.language 和网页首选语言；时区仍由出口 IP 决定，两者不必一致。改语言后下次启动会重算语言配置，设备指纹（UA / 屏幕 / 硬件）不变。已登录的老号建议一次设好、长期固定，别来回切。

      

        
        
      

      
      
时区固定留空：手填会让内核用 setdefault 覆盖 GeoIP 结果，造成「美国 IP + 手填时区」的矛盾。

      
      
网络诊断

      
尚未启动过，启动环境后这里会显示真实出口 IP、时区和代理状态。

      
修改屏幕/系统后，已生成过指纹的环境不会自动改变设备身份。重新生成指纹等于「换一台电脑」，已登录账号可能触发验证。
